# Notebooks

Run `00_inventory_exploration.ipynb` for offline analysis of the 52-record source manifest.

Install the optional environment with `python -m pip install -r requirements-notebooks.txt`, then start `jupyter lab` from the repository root. The notebook reads the local `seed_urls.json` and makes no network requests.

Do not put secrets, personal data, or unlicensed copied content in notebooks. Outputs may contain data, so review and clear notebook outputs before committing.
